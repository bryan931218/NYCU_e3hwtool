## 關鍵字回應

僅完全符合關鍵字時回覆，不攔截或解讀 `E3 <綁定碼>`；綁定驗證仍由現有 Webhook 處理。保留聊天及 Webhook 開啟，回應時間內使用「手動聊天＋自動回應訊息」，非回應時間使用「自動回應訊息」。原本的 Default「一律回應」已停用，但沒有刪除。

### 綁定教學

關鍵字：`綁定教學`。

```text
綁定 LINE，只需 3 步：

1. 登入網站，開啟通知設定。
2. 點「綁定 LINE」，將產生的整段綁定碼傳到這個聊天室（10 分鐘內有效）。
3. 收到綁定成功後，點下方「設定提醒」，選作業與提醒時間。新作業、到期前等自動通知條件可在網站設定。

https://www.e3hwtool.space/settings/notifications

請勿在聊天室傳送 E3 密碼或 MoodleSession。
```

### 通知說明

關鍵字：`通知說明`。

```text
你可以自行選擇接收：
・新作業、到期前提醒
・作業評分（分數與評語）
・課程公告、課程信件

點下方「設定提醒」，選作業，再選日期與時間；不需進網站。也可直接傳送「設定作業提醒」。
設定完成後可開啟作業或取消這筆提醒，時間以台灣時間為準。

調整項目、提醒天數或關閉 LINE 通知：
https://www.e3hwtool.space/settings/notifications
修改後記得點「儲存設定」。

沒收到通知？先確認網站顯示已綁定、LINE 通知已開啟，且未封鎖本帳號。若 E3 登入失效，請回網站重新登入。
```

## 驗證與維護

- 未登入時，課程訊息及通知設定會正常導向登入頁；作業首頁與問題回報可開啟。
- 圖文選單、兩則關鍵字回應及歡迎訊息應在後台分別檢查，不可只儲存草稿。
- 手機驗證：離開再進入聊天室，點綁定教學／通知說明，測試三個網站入口及「設定提醒」的選作業、日期時間、取消提醒流程。
- 綁定碼、評分與提醒由網站處理；本次後台設定不增加取得用戶課程或學號的權限。
- 未發送群發訊息、未變更方案、未修改 token 或 Webhook 網址。
- 若日後把這兩個教學指令改由 Webhook 處理，先停用後台同名規則，避免重複回覆。

## LINE 單一作業提醒

- 「設定作業提醒」「設定提醒」「安排提醒」由 Webhook 處理，不建立同名後台自動回覆。
- 先綁定帳號；若 LINE 通知關閉，聊天室會請用戶明確確認開啟，不更動其他提醒條件。
- 使用帳號最新同步的當期待處理作業，排除已完成、已評分、忽略及截止作業；每頁最多 8 筆。
- 日期時間須在未來且早於目前個人期限（未修改時以 E3 期限為準）。選作業及設定按鈕有效 15 分鐘，取消按鈕有效 7 天。
- 按鈕簽章綁定 LINE 使用者及網站帳號；重新綁定、過期、竄改與群組事件不會操作他人資料。
- 同帳號、作業與提醒分鐘重複提交只建立一筆提醒；取消後需選其他時間。
- 提醒仍由既有耐久佇列送出；送出前重新檢查作業狀態、期限、綁定與通知開關。不新增資料表或要求新的平台權限。
