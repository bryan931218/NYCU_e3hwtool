本政策由 {{ legal_entity_name }} 制定，並適用於所有使用 E3 作業追蹤系統（以下簡稱「本服務」）的學生與訪客。

1. 我們收集的資料

  • E3 認證資訊：登入時輸入的帳號密碼或 MoodleSession 值僅用於向 E3 平台取得課程資料。
  • Google OAuth 憑證：僅在使用者選擇日曆同步時，透過授權範圍 {{ google_scope }} 取得存取權杖與更新權杖。
  • 操作紀錄與流量資訊：包含 IP、請求時間、功能使用狀態、造訪頁面與來源分類及匿名統計數據，用於使用統計、偵錯與濫用偵測；頁面流量紀錄不保存完整來源網址或搜尋參數。
  • 偏好設定：顯示模式、篩選條件與 Google 同步選項等個人化設定。
  • 通知資料：僅在您啟用通知時，保存提醒條件、瀏覽器推播訂閱或綁定的 LINE 識別碼，以寄送您選擇的作業提醒。
  • 課程公告與信件：僅在您使用對應頁面時，從您的 E3 帳號讀取課程公告或收件匣，保存標題、寄件人、時間與已讀狀態；點開項目時才讀取內文及附件連結。

2. 資料使用方式

蒐集到的資料僅用於下列目的：

  • 登入 E3 並統整作業資料，以呈現個人化儀表板。
  • 分別呈現您的課程公告與信件；不代為寄信、回覆或刪除 E3 信件。僅在您開啟對應通知後，將課程名稱、訊息標題及本站連結送往您選擇的 LINE／瀏覽器裝置，不傳送信件內文，也不將信件送往 AI 服務。點開信件可能使 E3 將該信件標為已讀；本站已讀／未讀控制只變更本站狀態。
  • 在您允許的情況下，使用 Google API 將作業匯入指定日曆。
  • 在您啟用通知時，定期檢查 E3 作業，將課程名稱、作業名稱與截止時間送往您選擇的瀏覽器推播服務或 LINE 官方帳號。
  • 偵測異常流量、維護系統安全與品質，以及提供必要的客服協助。

3. 資料存放與保護

  • E3 密碼不會持久化；MoodleSession 與 Google Token 在後端以獨立金鑰加密，瀏覽器 Cookie 僅保留網站登入識別碼。憑證只提供給其對應的 E3 或 Google 服務，不存入 localStorage。
  • 課程信件快取以既有資料加密金鑰加密保存，與課程公告分開儲存；每個帳號與學期分別管理。刪除帳號時一併刪除公告與信件快取。
  • 訪客登入僅保留匿名的登入時間與結果，不保存訪客代號、IP 或其他個別活動紀錄。匯入資料及偏好僅供工作階段暫存，登出時刪除；未登出者於工作階段過期（預設 24 小時）後，在後續請求或系統啟動時清除。
  • 筆記原圖、文字與搜尋結果限管理員存取。啟用 AI 筆記功能時，相關內容會送交設定的 AI 服務處理；公開學習進度頁不公開筆記原圖或全文。
  • 機敏資料與操作紀錄僅限授權維運人員存取，並採取最小權限原則。
  • 作業系統的重要操作紀錄保留最近 90 天；近期動態不包含一般瀏覽頁面。今日使用人數以台灣時間每日去重統計，不計入訪客或背景通知發送。
  • 若您停止使用本服務，可透過客服信箱請求刪除相關資料。

4. 第三方服務

本服務僅串接下列第三方：

  • 國立陽明交通大學 E3 平台：作業、課程公告及課程信件的資料來源。
  • Google Calendar API：在授權範圍 {{ google_scope }} 內建立行事曆事件。
  • 瀏覽器推播服務與 LINE Messaging API：僅在您啟用對應通知時寄送作業提醒；訂閱與 LINE 識別碼在後端加密保存，您可在通知設定中移除。

我們不會販售個資；僅為提供您選擇的功能，向對應服務傳送必要資料。

5. 使用者權利

  • 如要撤銷 Google 授權，可在 Google 安全性中心或本服務中解除綁定。
  • 對本政策有任何疑問，可隨時與我們聯繫。
