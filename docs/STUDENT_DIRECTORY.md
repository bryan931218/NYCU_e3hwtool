# 後台年級與系所對照

更新日期：2026-10-25。僅供管理員統計與顯示，不參與登入、管理員判定或帳號合併。

## 學號格式

109 學年度起的新制九碼：`學制 1 碼 + 民國入學年末 2 碼 + 系所 3 碼 + 流水號 3 碼`。
學制：1 學士、2 學士後、3 碩士、4 博士、5 碩士在職專班。
例如 `315550001` 是 115 學年度入學的碩士，不能把 `315` 當成入學年。
未支援的舊制、非九碼、無法確認的學制與入學年不強行轉換。

## 顯示與更新規則

1. 僅從已驗證本人 E3 個人資料中的明確欄位讀取系所與年級；不從課程名稱、名冊或任意頁面文字推斷。
2. E3 系所優先於入學系碼，避免轉系者仍被原系覆蓋。E3 年級只在記錄所屬學年度等於本學年度、學制一致時使用。
3. 沒有 E3 年級時，以台北日期及 8 月 1 日學年度分界推估入學第幾年，明示「推估」。不能據此判斷實際在學、休學、轉系、跳級或畢業狀態。
4. 同一已驗證學號的登入別名在統計顯示上去重；不更改帳號儲存鍵或授權。
5. 一般帳密登入完成後排入既有有界背景佇列；Session 登入沿用本人資料補抓。舊帳號隨有效登入或背景補抓逐步補齊，無有效 E3 憑證時不能代取學籍。
6. 只保存系所、年級、學制、對應學年度、檢查時間與固定錯誤代碼；不保存上游 HTML、編輯欄位、Cookie 或錯誤訊息原文。這些資料不送到 GA4，也不加入公開個人資料 API。
