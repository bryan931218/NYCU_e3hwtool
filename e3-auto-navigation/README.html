E3 作業自動跳轉

安裝一次後，從 E3 作業追蹤系統按「前往 E3」。已登入時直接開啟；需要登入時，自動開啟校園單一入口，登入完成後自動返回原作業。

  1. 保留這個含有 manifest.json 的資料夾，不要刪除或移動。
  2. 桌機 Chrome 開啟 chrome://extensions，Edge 開啟 edge://extensions。
  3. 開啟「開發人員模式」，按「載入未封裝項目」，選取這個資料夾。
  4. 重新整理 https://www.e3hwtool.space/，即可使用。

只適用桌機 Chrome／Edge 與 e3hwtool.space、www.e3hwtool.space、e3p.nycu.edu.tw。手機 Chrome 不支援桌機擴充套件。

不收集或儲存密碼、Cookie 或驗證碼，不會把 E3 登入憑證傳回追蹤系統。學校登入與二階段驗證仍由使用者在校方頁面完成。

作業目標只保留於瀏覽器的套件暫存中。完成跳轉或關閉分頁時清除，超過 30 分鐘不再自動跳轉；關閉瀏覽器也會清除。沒有從本工具開啟作業時，不會介入 E3 瀏覽。

更新版本時下載新套件，替換資料夾內容，再於擴充功能頁按「重新載入」。可隨時移除套件來停用。
